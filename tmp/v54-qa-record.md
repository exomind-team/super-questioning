## P0 修订项（六项）

### 1. D7/D8 有机整合进 SKILL.md

**用户决策**：
- D7、D8 直接融入 SKILL.md 主流程，不拆分文件
- 八维度是有机结合，不是四分五裂

**影响**：

- 取消「不在维度追问途中插入 D7/D8」的表述
- D7/D8 是 Agent 提问时同时调用的维度，不是单独的执行阶段

### 2. 框架性质重定义

**用户决策**：
- D1-D6 是覆盖状态报告工具，不是提问顺序
- Agent 提问时综合调用所有维度，按实际问题灵活组合
- 不是固定的六个问题，而是考量问题的六个维度

**影响**：
- 主流程图重构：「六维度顺序覆盖」→「六维度综合考量」
- 维度覆盖状态报告格式不变，但明确其是「状态工具」而非「执行步骤」

### 3. 朴素停止条件 — 新增第三条

**用户决策**：
- 「问无可问/不能以及不需要再继续问下去」新增为第三条收敛条件

**当前朴素停止条件（修订后）**：
1. D1/D4/D5（高风险维度）已充分覆盖
2. 连续两轮追问没有产生新的计划相关信息
3. **问无可问——Agent 主观判断无法再通过提问推进讨论，且用户也确认没有遗漏**

### 4. 新信息定义 — D7 场景补充

**用户决策**：
- 修改 L115 + L119 新信息定义
- 核心洞见：「能追问出新信息，就意味着还有新计划信息」——二者不冲突
- 思维展开本身（更清晰/更具体/过程更完整）= 新信息
- 旁观者视角：用户立场实质性移动（看见新角度、承认盲区、重构问题）= 新信息

**修订后 L119 补充定义**：
> **D7追问场景的补充标准**：D7-A 逐层追问时，用户对思维过程的任何实质性展开（思路更清晰、依据更具体、过程更完整）均计入新信息；D7-B 旁观者视角触发后，用户立场的任何实质性移动均计入新信息。

### 5. D7-A 操作层次 — L4 恢复「追问依据」

**用户决策**：
- 恢复「追问依据」替换当前 L4「追问反面」
- 「追问反面」降为 L3 的次级追问

**修订后 L1-L5 层次**：

| 层次 | 触发条件 | 追问方向 | 示例句式 |
|------|---------|---------|---------|
| L1 | 用户给出结论/方案 | 追问来源 | 「这个方向，是怎么想到的？」 |
| L2 | 用户说「我认为」 | 追问过程 | 「你思考这个问题的过程是怎样的？」 |
| L3 | 用户说不清楚 | 追问尝试 | 「那你先尝试了什么路径？后来怎么调整的？」 |
| L4 | 用户很确定 | 追问依据 | 「你为什么这样判断？支撑这个结论的证据是什么？」 |
| L5 | 多轮后仍浅 | 追问规律 | 「这类问题的共同规律是什么？」 |

L3 次级追问：「有没有哪个方向是你刻意没选的？为什么？」

### 6. P0 预备冲突 — D7-B 直接触发 vs D1-D6 顺序框架

**用户决策**：
- 采用 d7-d8.md 逻辑：D7-B 在情绪化/框架卡死时直接触发
- 取消「先完成 D1-D6 再触发 D7/D8」的顺序约束

**影响**：

  - D7/D8 是 Agent 综合调用时的有机维度
  - 无固定顺序，根据用户状态按需触发

## 用户额外补充的设计洞见

### 「尚不清楚」作为合法锚点答案

- 用户回答「尚不清楚」本身是被允许的
- 这不是失败，而是被标记为⚠️维度缺口
- 不阻断追问继续，Agent 继续覆盖其他维度

### 选项 + 说明降低回答门槛

- 只要提供了选项和说明，追问不会难倒用户
- 选项本身即是降低认知负荷的设计
- 「尚不清楚」是预设的兜底选项

### Agent 计划停止条件的双层结构

- 客观条件：D1/D4/D5 覆盖 + 无新信息
- 主观条件：问无可问（Agent 主观判断 + 用户确认）
- 两者结合，缺一不可停止
