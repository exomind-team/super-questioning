# 叶修提问法体系整理

> 来源：叶修《很多人不是问题解决不了，而是根本不会提问》（学习策略师公众号）
> 整理日期：2026-04-16

---

## 1. 核心观点提取

### 1.1 最核心的论点

**大部分人的问题不是「解决不了」，而是「根本不会提问」。**

叶修的核心主张是：人们向他人求助时表现出的无能，主要不是因为问题太难，而是提问者本身缺乏提问能力——这种缺陷是系统性的，不分线上线下，也不分提问者的学历背景。

### 1.2 「不会提问」的根本原因分析

叶修对根本原因的分析分为三个层次：

**第一层：缺乏具体化意识**
- 提问者不知道自己的问题是抽象的
- 他们默认回答者天然了解自己的背景，而实际上对方只有极有限的信息
- 典型例子：学生认为「每天见面的老师一定很了解我的情况」——实际上老师注意力平摊给几十个学生，每次交流只有几十分钟

**第二层：思维过程不透明**
- 提问者不知道自己真正需要的是什么
- 他们要的是「这个题怎么做」（答案），但真正有价值的是「学霸是怎么想到的」（思维过程）
- 回答者可能自己也不清楚自己的思维过程（「自然而然想到了」），但这并不代表没有价值挖掘

**第三层：利益攸关损害认知**
- 当问题对提问者特别重要时，提问者给了回答者「用回答影响自己心智」的权力
- 利益攸关的状态使提问者的思维受限，无法客观评估答案质量
- 常见场景：被学霸随口一句「这题都不会」引发情绪波动，干扰了信息接收

## 2. 方法论体系梳理

### 2.1 方法一：具体化原则（基础层）

**名称**：具体化原则 / 添加充分背景信息

**原文依据**：
> 「问问题的一个基本要点，是问题要具体，不要太抽象。这是提问的最基础、最容易理解的原则。」
>
> 「如何避免问问题太抽象？最简单的方法是，添加足够的背景信息。」

**操作说明**：
- 不要只说「数学学不好」，要描述：成绩演变轨迹（小学→初中→高中）、具体分数范围、失败场景（哪类题出错）、尝试过的方法及效果
- 提供具体背景信息的作用是让回答者可以从信息中**推断**问题根源，而不是回答一个根本无法回答的抽象问题
- 好的背景信息 = 时间线 + 具体数字 + 典型场景 + 已尝试的方法

**层次关系**：这是整个提问体系的**第一层基础**，任何进阶技巧都依赖于此。

---

### 2.2 方法二：反复聚焦追问（进阶层）

**名称**：反复聚焦连续提问 / 追问法（Iterative Focusing）

**原文依据**：
> 「提问的另一个进阶的要点，是抓住核心过程和细节不断聚焦。」
>
> 「你提问的方式弱爆了——这个题怎么做？」
>
> 「你需要反复聚焦，再次提问。下一个问题是：你是怎么想到这个思路的？」
>
> 「如果学霸不能给你一个完整的结论的话，你就往过程上去聚焦和提问：『那么你思考的过程是怎样的？你是一开始就想到这个思路了吗？还是先尝试了些其他的思路？』」
>
> 「通过这种反复聚焦，你能把学霸的思维过程问出来，把他的核心竞争力问出来，问的他感觉自己的大脑好像要被掏空了一样……」

**操作说明（多层级聚焦路径）**：

| 层级 | 问题示例 | 聚焦目标 |
|------|---------|---------|
| L1 | 这个题/方案怎么做？ | 答案层（通常价值最低）|
| L2 | 你怎么想到这个思路的？ | 思路来源层 |
| L3 | 思考的过程是怎样的？先想到思路还是先尝试了其他方法？ | 过程层 |
| L4 | （如果学霸含糊）为什么是这条路而不是其他路？| 决策依据层 |
| L5 | 你觉得这类题的共同规律是什么？ | 规律层（元认知）|

**关键规则**：每次回答后，如果答案不令人满意，就往「过程→依据→规律」方向继续深挖。

**层次关系**：这是**第二层进阶**，在具体化基础上，主动控制信息质量，将回答引导至核心层。

---

### 2.3 方法三：旁观者提问（高级层）

**名称**：旁观者提问法（Observer-Perspective Questioning）

**原文依据**：
> 「当你提问的时候，你不要作为直接提问者，你可以使用旁观式的提问。」
>
> 「你觉得A的学习状态怎么样？你觉得A这种人要想学好该怎么办？」
>
> 「这种做法的好处是，你可以站在旁观者清的位置上去看待问答的过程，也避开了不良答案对你的负面作用。」
>
> 「你还可以向多个学霸或者老师进行旁观式提问，然后比较不同人的回答。在大量的比较当中，你可以更加客观的理解问题。」

**操作说明**：
1. 将自己的问题转化为「第三人的问题」：不问「我该怎么办」，而问「你觉得XX同学/这类人该怎么办」
2. 多角度旁观：对多个回答者（A、B、老师等）都使用旁观式提问，比较他们的答案
3. 旁观式视角的作用：
   - 认知上去除利益攸关的思维局限（「我」的焦虑被悬置）
   - 情绪上避免被不良答案伤害（不是直接说给我听的）
   - 信息上通过比较获得更客观的理解

**层次关系**：这是**第三层高级技巧**，在掌握前两层的基础上，用视角转换彻底解决「当局者迷」问题。

---

### 2.4 方法体系总览：层次关系图

```
┌─────────────────────────────────────────────────┐
│  L3  旁观者提问（高级）                          │
│       视角转换：去除利益攸关干扰，多人比较       │
├─────────────────────────────────────────────────┤
│  L2  反复聚焦追问（进阶）                        │
│       路径：答案→思路→过程→依据→规律           │
│       核心：从「是什么」追问到「怎么想到的」     │
├─────────────────────────────────────────────────┤
│  L1  具体化原则（基础）                          │
│       添加充分的背景信息（时间线+数字+场景）     │
└─────────────────────────────────────────────────┘
```

**元方法（关于如何提问的方法）**：

叶修提出了一个**二阶提问元方法**，可以指导所有其他提问技巧：

> **「先问『回答者是否真正知道答案』，再决定追问方向」**
>
> 学霸可能：（A）知道且能说清楚 → 追问思路来源
> 学霸可能：（B）做对了但说不清（潜意识/题感）→ 追问过程和尝试步骤
> 学霸可能：（C）不知道（基础弱）→ 回到基础层解决

## 3. 与 AI 使用的关联

### 3.1 文章是否涉及 AI 时代提问的变化

**文章本身未直接讨论 AI**——这是一篇面向中学生的教育方法论文章，写作背景是学生向老师/学霸提问的场景。但文章的方法论**完全适用于 AI 时代**，甚至某些维度更关键。

### 3.2 AI 时代对提问者提出的新要求

从叶修方法论延伸到 AI 场景，可以推理出以下新要求：

| 要求 | 原因 | 叶修方法的对应 |
|------|------|--------------|
| **具体化更关键** | AI 的背景信息 = 零，记忆不跨会话 | L1 原则直接适用 |
| **追问成为核心能力** | AI 第一轮回答往往是概述，需追问才能深入 | L2 反复聚焦直接适用 |
| **旁观式元认知** | 需要监控 AI 输出质量，不被权威感带偏 | L3 旁观者视角适用 |
| **识别 AI 的「学霸困境」** | AI 可能「自然地给答案」但说不出依据 | L2 中的「学霸说不清」判断适用 |
| **主动提供思维过程提示** | 需要告诉 AI「不要只给答案，要解释思路」 | L2 中的「追问→过程」提示 |

## 4. 可操作化要素

### 4.1 问题模板与句式

**具体化模板**（L1）：
```
问题框架：
"我的情况：[背景描述，包括时间线/成绩/已尝试方法]
具体困境：[精确描述，不是抽象的'学不好'，而是具体场景]
我想问的是：[一个具体的、可以回答的问题]"
```

**追问聚焦模板**（L2）：
```
第一轮：直接问题
→ 回答后触发：

追问层级句式：
L2: "你是怎么想到这个方法的？"
L3: "你思考的过程是怎样的？是一开始就想到这个方向，还是尝试过其他路径？"
L4: "这个方法相比其他方法的优势是什么？为什么选它而不是另一个？"
L5: "这类问题的一般规律是什么？有没有更底层的原理？"
```

**旁观者提问模板**（L3）：
```
"假设有一个和你情况相似的同学，他遇到的问题是[复述你的问题]，你建议他怎么办？"
"如果是我一个朋友遇到这种情况，你觉得可以从哪几个角度来分析？"
```

### 4.2 判断标准

**坏问题特征**：
- 抽象到无法回答（「该怎么办」「怎么学好」）
- 没有提供任何背景信息
- 只有一个问题，没有说明已尝试过什么
- 问题指向回答者的能力而非自己的思维过程
- 对利益攸关的状态毫无觉察

**好问题特征**：
- 有具体背景信息（时间线、数字、场景）
- 已经过自己思考（说明了已尝试什么、结果如何）
- 问题指向**思维过程**而非仅指向答案
- 对回答者的局限性有预期（不默认对方天然理解自己的处境）
- 包含自我评估（自己觉得可能是什么原因）

### 4.3 训练方法与自我检查清单

**自我检查清单**（提问前）：
```
[ ] 我的问题是否具体到可以回答？（不是抽象概念）
[ ] 我是否提供了充分的背景信息？（时间线、数字、场景）
[ ] 我是否说明了已尝试过的方法和结果？
[ ] 我的问题是指向"答案"还是"思维过程"？
[ ] 我是否对"我以为我理解了"有警觉？
[ ] 如果用旁观者视角重述我的问题，会怎样问？
```

**训练方法**：
1. **降维练习**：把抽象问题转化为具体问题（每天选一个抽象问题，写出 5 个具体化版本）
2. **追问链练习**：对每个回答，强制自己再问 2 个追问（为什么？怎么想到的？）
3. **旁观者练习**：把自己的问题转述给 AI 或他人，观察对方的理解与自己的理解有多大偏差
4. **逆向练习**：先猜回答者的答案，再提问，看自己的猜测是否准确

## 5. 哲学/认知层面

### 5.1 哲学假设

叶修的文章背后隐含以下哲学假设：

**关于知识**：
- 知识不是简单的「答案集合」，而是**思维过程和决策路径**
- 知道答案不等于理解答案是如何产生的
- 学霸的优势不在于记住了更多答案，而在于**更高效的思维路径**

**关于认知**：
- 人的认知天然受限（「不识庐山真面目，只缘身在此山中」）
- 利益攸关会系统性地损害认知判断（情绪干扰 + 确认偏误）
- 信息不对称是常态，提问者应**不默认**对方理解自己的处境

**关于学习**：
- 学习不是记忆答案，而是构建**可迁移的思维模型**
- 提问的终极目的是提取「学霸的思维模型」，而非该题的解法
- 「学霸还处于已经很厉害但还不通透的状态」——这说明掌握和通透之间还有距离

### 5.2 与苏格拉底式追问（Socratic Questioning）的呼应

| 苏格拉底式追问 | 叶修方法 | 异同 |
|--------------|---------|------|
| 概念澄清（What do you mean by...?）| 具体化原则 | 一致：追问概念的精确含义 |
| 假设追问（What are you assuming?）| 旁观者视角（去除利益攸关的假设）| 一致：识别隐性假设 |
| 证据追问（What evidence for that?）| 反复聚焦（追问依据/过程）| 一致：不停留于断言 |
| 观点追问（Whose viewpoint?）| 旁观者提问（多角度比较）| 一致：多元视角 |
| 影响追问（What are the implications?）| L4/L5 聚焦（追问后果/规律）| 一致：追问深层影响 |
| 元追问（Why do you think that?）| 追问「怎么想到的」| 一致：追溯思维来源 |

**核心区别**：苏格拉底式追问更偏向**批判性思维**（检验论证的有效性），叶修的方法更偏向**认知获取**（提取专家的思维模型）。叶修的框架更实用主义，服务于「学习」而非「辩论」。

## 6. 对 super-questioning skill 的整合建议

### 6.1 叶修方法对六维度的补充

现有 super-questioning 的六维度（D1–D6）聚焦于**需求覆盖**，叶修的方法论提供了**提问质量控制**的维度，两者互补。

**新增建议维度 D7：问题具体性（Question Specificity）**

| 维度 | 定义 |
|------|------|
| D7 | 问题是否足够具体可答？是否提供了充分背景信息？|

对应的核心问题：
- 「这个问题是否抽象到无法回答？」
- 「是否提供了足够的时间线、数字、场景？」
- 「对方在没有你的背景知识的情况下能否理解？」

**D8：思维过程导向（Process Orientation）**

| 维度 | 定义 |
|------|------|
| D8 | 问题是否指向思维过程而非仅指向答案？|

对应的核心问题：
- 「这个问题是在追问『怎么做的』还是『为什么』？」
- 「是否已经穷尽了第一轮答案？」
- 「是否已追问到可迁移的思维模型/规律？」

**D9：认知去偏（Perspective Detachment）**

| 维度 | 定义 |
|------|------|
| D9 | 提问者是否识别并缓解了利益攸关的认知偏差？|

对应的核心问题：
- 「我是否处于情绪激动的状态？」
- 「用旁观者视角重述问题，会改变问题本身吗？」
- 「我已经连续追问了几个层级？」

### 6.2 直接可整合的具体技巧

**整合点 1：提问前的具体化检查（可并入 SKILL.md 的 Trigger Criteria）**

在 super-questioning 激活时，增加一条「具体性预检」：
```
激活 super-questioning 前，先确认：
[ ] 问题已具体化（不是抽象概念）
[ ] 已提供必要的背景信息
若未满足，则优先引导用户具体化，而非直接进入六维度覆盖。
```

**整合点 2：追问路径模板（并入问题质量标准）**

当前 SKILL.md 没有追问路径。叶修提供了现成的操作模板：
```
追问链操作规程：
1. 若回答为结论性断言（"因为……"）→ 追问"怎么想到的/依据是什么"
2. 若回答为主观判断（"我认为是……"）→ 追问"有没有反例/什么时候不成立"
3. 若回答者说不清 → 追问"先尝试了什么路径？后来怎么调整的？"
4. 若多轮追问后仍不清晰 → 切换旁观者视角，让回答者描述第三人情况
```

**整合点 3：旁观者提问模板（并入问题质量标准的「多元视角」维度）**

当 AI 发现用户的问题带有强烈利益攸关色彩时，可使用旁观者提问模板：
```
「如果用旁观者视角来描述这个问题，你会怎么问？」
「如果是一个和你情况类似但情绪更平静的朋友，他会怎么描述这个问题？」
「你觉得学霸会怎么描述一个处于你当前困境的人？」
```

**整合点 4：好问题/坏问题判断标准（并入六维度定义区）**

叶修的具体化判断可作为 D7 的操作定义：

**坏问题标记**（自动触发追问引导）：
- 问题无法用「是/否」以外的方式回答
- 包含「该怎么办」「怎么学好」「如何提高」等无边界词
- 无任何背景信息
- 仅描述情绪状态，无具体事件

**好问题标记**：
- 有时间线或数字
- 说明了已尝试的方法及结果
- 问题指向思维过程或具体操作
- 可在 5–10 分钟内给出有价值的回答

### 6.3 现有 SKILL.md 未覆盖的独特视角

| 叶修独特视角 | 当前 SKILL.md 缺失 | 整合建议 |
|------------|-----------------|---------|
| **「学霸困境」识别**（回答者说不出依据，但确实有深层知识）| 当前只关注问题质量，未关注回答者状态| 增加对「回答质量」的预判能力，当回答者含糊时自动触发过程追问 |
| **连续追问直到「大脑被掏空」的标准**| 当前六维度是静态覆盖，无追问深度概念| 增加「追问深度」指标：答案层(L1) → 思路层(L2) → 过程层(L3) → 规律层(L4) |
| **「利益攸关」的元认知**| 当前 SKILL.md 没有情绪/认知偏差维度| 增加 D9 维度或在 D1（隐性需求）中增加认知偏差识别子项 |
| **多视角比较法**（向多个回答者提问并比较）| 当前是单轮问答模型| 在复盘模式中增加「比较异同」提问，引导用户综合多个视角 |
| **「不默认对方了解我」的元规则**| 当前默认提问者已提供充分信息| 在触发条件中明确：若用户未提供背景信息，优先要求具体化 |
